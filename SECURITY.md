# Security Policy

## Reporting a Vulnerability

The security of NusaForge and its users is important.

If you discover a potential security vulnerability, please report it privately to the project maintainer through an established private contact channel.

Do not publish sensitive vulnerability details, credentials, API keys, or exploit instructions in public issues.

## What to Include

When reporting a vulnerability, include:

- A description of the affected component.
- The potential impact.
- Steps to reproduce the issue, where safe.
- The affected package version.
- Any relevant technical details.

Please remove personal information, secrets, and unrelated sensitive data.

## Response Process

The maintainer will review reports as time and resources permit. A report does not guarantee a particular response time or a security release.

Please avoid publicly disclosing unpatched vulnerabilities before coordinating with the maintainer.

## Supported Versions

Refer to the official npm package page for published versions:

https://www.npmjs.com/package/nusaforge

## Responsible Disclosure

Thank you for helping improve the security and reliability of NusaForge.
