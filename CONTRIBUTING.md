# Contributing to NusaForge

Thank you for your interest in contributing to NusaForge.

We welcome constructive feedback, bug reports, documentation improvements, and ideas that help make the project better.

Our goal is to build practical software through collaboration, continuous learning, and thoughtful engineering.

## Ways to Contribute

You can contribute to NusaForge in several ways:

- **Report Bugs** — Identify unexpected behavior and provide clear reproduction steps.
- **Suggest Features** — Propose improvements that align with the project's goals.
- **Improve Documentation** — Help make instructions and explanations clearer.
- **Submit Code** — Contribute fixes or improvements when code contributions are supported.
- **Share Feedback** — Help identify usability issues and opportunities for improvement.

## Before You Start

Before submitting a contribution:

1. Review the existing documentation.
2. Check existing issues or discussions to avoid duplicate reports.
3. Make sure your proposal is relevant to the project's purpose.
4. Keep your changes focused and easy to review.

## Reporting Bugs

When reporting a bug, please include:

- A clear and descriptive title.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Relevant error messages or logs.
- Environment details, when applicable.

Please remove passwords, access tokens, API keys, and other sensitive information before sharing logs.

## Suggesting Features

Feature suggestions should explain:

- The problem you want to solve.
- Why the improvement would be useful.
- How the proposed feature could work.
- Any relevant examples or alternatives.

Clear, practical proposals are easier to evaluate.

## Pull Requests

If code contributions are accepted for this repository:

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Write a clear commit message.
5. Submit a pull request describing your changes.

Keep pull requests focused on a single purpose whenever possible.

Please do not include unrelated changes, generated files, credentials, or private information.

## Code Quality

Contributions should prioritize:

- Readability and maintainability.
- Consistent formatting and naming.
- Appropriate error handling.
- Clear documentation for user-facing changes.
- Tests for relevant functionality, where applicable.

Follow the conventions already established by the project.

## Documentation Contributions

Documentation improvements are welcome.

Please ensure that examples, installation instructions, commands, and feature descriptions accurately reflect the current implementation.

Avoid documenting features that have not yet been implemented.

## Security Issues

Do not disclose sensitive security vulnerabilities in public issues.

Use an established private contact channel to report potential vulnerabilities responsibly.

## Community Guidelines

All contributors are expected to communicate respectfully and constructively.

We value different perspectives, useful feedback, and collaboration focused on improving the project.

## Questions

For project information and installation details, visit:

https://www.npmjs.com/package/nusaforge

Thank you for helping NusaForge grow.
