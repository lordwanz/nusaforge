# Support

Thank you for using NusaForge.

## Getting Help

Before requesting support, please:

1. Read the project's README.
2. Review the installation and usage documentation.
3. Check the FAQ for common questions.
4. Verify that you are using the intended package version.

## Bug Reports

If the repository has an enabled issue tracker, use it to report reproducible bugs.

Include:

- The NusaForge version.
- Your operating system and Node.js version, when relevant.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Relevant error messages.

Never include passwords, private keys, access tokens, or other secrets.

## Feature Requests

When proposing an improvement, explain the problem, the intended outcome, and why the change would be useful.

## Security Issues

Do not report sensitive vulnerabilities through public issues. Follow the instructions in [SECURITY.md](SECURITY.md).
