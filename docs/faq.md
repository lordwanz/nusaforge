# Frequently Asked Questions

## What is NusaForge?

NusaForge is a software project distributed through npm. Refer to the package documentation for its current purpose and capabilities.

## How do I install NusaForge?

Run the following command in your project directory:

```bash
npm install nusaforge
```

## How do I check the installed version?

Run:

```bash
npm list nusaforge
```

## Where can I find the latest release?

Visit the official npm package page:

https://www.npmjs.com/package/nusaforge

## Why does installation not provide a command?

Not every npm package provides a command-line interface. Check the package's documented usage and its `bin` configuration.

## How do I report a bug?

Use the official repository's issue tracker if one is available. Include the package version, environment details, reproduction steps, and relevant error messages.

Remove credentials and other sensitive information before sharing logs.
